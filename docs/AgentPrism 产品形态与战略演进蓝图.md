# AgentPrism: 产品形态与战略演进蓝图

## 1. 核心产品哲学：精密、克制、全视之眼

在百模大战和 Agent 满天飞的时代，开发者的电脑后台如同一个喧闹的暗箱。**AgentPrism（算力棱镜）** 的诞生，不是为了制造更多的喧哗，而是作为一面冷静的棱镜，将暗箱中混沌的 Token 消耗，折射出清晰、透明、结构化的数据账本。

它不是一个“生产力工具”，而是一个**“精密测量仪器”**。它的存在感应该极低，但当你需要它时，它提供的数据必须绝对精准、优雅且不可篡改。

## 2. 产品形态与体验预期

作为一款常驻桌面的监控工具，AgentPrism 的视觉和交互必须恪守“少即是多”的原则，绝不和主工作区抢夺注意力。

### 2.1 系统托盘：安静的“数字心跳”
*   **状态隐喻**：任务栏的图标不只是一个静态 Logo，它可以是一个极其微小的“状态指示器”。当后台 Codex 或 Claude 正在疯狂消耗 Token 时，图标可以有极其轻微的呼吸感或亮度变化，就像系统的“算力脉冲”。
*   **极简概览菜单**：点击托盘图标，弹出的不是密密麻麻的报表，而是一个具有空气感的悬浮面板。
    *   **核心视窗**：这里可以融入**“进度圆环”**概念——用一个极简的闭合圆环，展示“今日 Token 预算”的消耗进度。
    *   **关键指标**：只显示两行字：今日预估账单（如 `$1.24`）和当前最活跃的 Agent。

### 2.2 主控看板：深邃的“数据折射”
当用户需要复盘时，呼出的主面板是一块充满现代极客美学的仪表盘。
*   **材质与光影**：摒弃传统的白底黑字，采用无边框设计（Frameless），直接调用 macOS 的 `NSVisualEffectView` 或 Windows 的 `Mica` 材质。整个面板呈现一种带有毛玻璃质感的深色系（Dark Mode 首选），仿佛数据是悬浮在系统桌面之上的。
*   **色彩克制**：全局采用黑、白、高级灰。只有在展示特定模型（如区分 Codex 和 Claude）或触发预算超支警告时，才克制地使用一两种低饱和度的强调色（如荧光蓝或琥珀色）。
*   **排版即 UI**：重度依赖优秀的字体排印（Typography）来划分信息层级，而不是使用生硬的边框和卡片。用巨大的、纤细的无衬线数字来展示总 Token 数，带来直观的视觉冲击。

### 2.3 交互体验：无感与掌控
*   **无感统计**：所有的 JSONL 日志解析和 SQLite 并发读取都在后台静默完成，前端 UI 永远保持 60fps 的丝滑响应，没有任何卡顿。
*   **优雅阻断（后期规划）**：当某个死循环项目导致 Token 异常飙升时，AgentPrism 不会弹出一个廉价的错误框，而是通过系统原生的 Notification 提供一个柔和但明确的警告：“Codex 消耗异常，已达设定的软阈值”。

## 3. 技术演进策略与战略方向

在技术选型上，不关注具体怎么写循环，只关注架构能否支撑产品的“野心”。

### 3.1 核心选型：Tauri 单体架构
*   **战略考量**：对于一个常驻任务栏的“监控探头”，**内存占用是生死线**。放弃厚重的 Electron，选择 Tauri（Rust + Web）架构。
*   **价值交付**：让前端 Vue 专注实现毛玻璃、流畅动画和极客图表，让后端的 Rust 去干脏活累活（多线程文件 I/O、数据库高频检索）。最终交付给用户的是一个体积十几兆、内存只占几十兆的原生级应用。

### 3.2 数据基建：从第一天起面向“多 Agent”
*   **底层抽象**：MVP（最小可行性产品）虽然只做 Codex，但在数据库设计和架构接口上，直接抽象出 `AgentSource` 概念。
*   **双向校验引擎**：确立“SQLite 做总账，JSONL 做明细”的对账逻辑。确保未来接入 Claude Code 或 Gemini CLI 时，这套对账引擎依然适用。

### 3.3 计费与隔离策略
*   **动态估算模型**：绝不写死任何一行价格代码。所有的 Token 计费（Input, Output, Cached, Reasoning）必须基于一个可配置的计费矩阵，未来支持一键从云端拉取最新的大模型价格表。
*   **绝对的本地安全**：作为产品的底线承诺，AgentPrism 绝不内置任何上传埋点或联网分析模块，所有的算账逻辑 100% 在本地沙盒闭环，获取极客用户绝对的信任。

## 4. 里程碑规划

1.  **V0.1 (探针时代)**：完成本地 Codex 数据的精准读取与去重，跑通 Tauri 前后端通信，实现极简的系统托盘和单日总账展示。
2.  **V0.5 (透视时代)**：上线主控看板，完成项目维度、模型维度、时间维度的数据折射与可视化（引入圆环预算 UI）。
3.  **V1.0 (全视时代)**：正式抽象化 Agent Source 接口，平行接入 Claude Code 等至少两款主流 Agent 工具，成为名副其实的 AgentPrism。
